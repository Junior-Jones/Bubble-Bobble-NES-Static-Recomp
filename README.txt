Bubble Bobble (NES) Static Recomp 1.0.0

The original game ROM is not included. Place your legally obtained Bubble Bobble (USA), .nes, NTSC-U ROM in the Rom folder.

Open Launcher.exe. Browse changes to Run when the exact supported ROM is found. Player 1 uses the arrow keys for the D-pad, F for A, D for B, S for Start, and A for Select. Frontend shortcuts use F1 through F8. Escape switches between the game and Launcher.

The Music toolbar button opens the 36-entry sound catalogue. The Windows frontend also provides settings, controller bindings, full-screen mode, Auto-Run, snapshots, and game-window captures.

Build with Visual Studio 2022 and CMake. See README.md and docs/BUILD-WINDOWS.txt for details.
