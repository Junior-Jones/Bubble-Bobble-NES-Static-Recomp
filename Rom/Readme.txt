Use your own clean Bubble Bobble (USA) NES cartridge dump (NTSC-U).
Place the .nes or .bin file in this Rom folder or select it with Browse ROM.
The launcher verifies the game data regardless of the filename.

Supported formats:
- iNES or compatible NES 2.0 with an MMC1 mapper 1 header, horizontal
  mirroring flag and no trainer, battery or four-screen flag. NES 2.0
  uses submapper 0, NTSC timing and no cartridge RAM or auxiliary ROMs.
- Headerless dump with 131,072 bytes of PRG followed by 32,768 bytes of CHR.

The combined PRG+CHR SHA-256 is:
31523322db8f94e7244f6e2d958692a412c1395fc744601d83d1e5111eff9042

"PRG+CHR SHA-256 does not match" means the game data differs from the
supported USA edition. "Unsupported mapper" or "unsupported mirroring flag"
means the header describes an incompatible board configuration.
"Truncated ROM payload" or "unexpected ROM length" means the file is
incomplete or contains extra data. Select a clean, uncompressed dump.

The game ROM is supplied by the player.
